# Pokémon Mobile App

A Flutter Pokémon application built with Riverpod and a layered structure for controllers, models, providers, services, pages, and widgets.

## Features

- Pokémon list loaded from a remote data service
- Incremental loading while scrolling
- Favorite Pokémon collection
- Local favorite persistence
- Reusable Pokémon cards and list items
- Loading-state UI

## Tech Stack

- Flutter
- Dart
- Riverpod
- Dio
- GetIt
- SharedPreferences
- Skeletonizer
- Google Fonts

